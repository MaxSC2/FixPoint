# FixPoint UI prototype

This directory contains the static, non-production UI reference for the visual direction and client journey. It is a prototype only: data and interactions are illustrative and must not be presented as a live backend implementation.

- `index.html`: public landing page.
- `client.html`: client dashboard/request view.
- `assets/styles.css`: prototype styles.
- `assets/app.js`: small client-side interactions.

The production PHP views must be built against `docs/10-INTEGRATION-CONTRACT.md`. Do not copy prototype-only fake data into production controllers or seed fixtures as real records.
