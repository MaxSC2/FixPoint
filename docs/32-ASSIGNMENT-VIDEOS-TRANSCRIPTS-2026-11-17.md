Транскрипты собраны по последней строке каждого кадра с дедупликацией; для всех 31 файла проверено, что финальная реплика транскрипта совпадает с финальной репликой дорожки — обрезаний нет.

### Ограничения

- Это машинное распознавание: термины и латиница искажаются (`тегметарипtion` = `meta description`, `Editтек` = `edit_text`, «инклуд» = `include`). Смысл реплик передан, дословная цитата требует сверки с видео.
- У 29 видео английская автопереведённая дорожка не скачалась (HTTP 429). На русские дорожки это не влияет.
- Код в видео показывается на экране и в речи проговаривается частично, поэтому имена файлов и SQL восстановлены по контексту и помечены как вывод, а не как дословная цитата.

### Видео 1 — редактирование текстов страниц

Задача: дать администратору менять `title`, `meta description`, `meta keywords` и полный HTML-текст каждой из четырёх страниц (`index`, `articles`, `lessons`, `contacts`), которые хранятся в таблице `settings`.

Реализация в уроке:

- `edit_text.php` — копия `edit_lesson.php`: `SELECT title, id FROM settings` + цикл `do…while` со ссылками `edit_text.php?id=…`; при наличии `id` — `SELECT * FROM settings WHERE id=…` и форма с полями title / meta_d / meta_key / text + скрытое поле `id`.
- `update_text.php` — копия `update_lesson.php`: проверки `isset()` для title, meta_d, meta_key, text; `UPDATE settings SET title=…, meta_d=…, meta_key=…, text=… WHERE id=…`; сообщения «страница обновлена / не обновлена / введена не вся информация».
- Ссылка «Редактировать тексты» в левом блоке админки ведёт на `edit_text.php`.
- Автор по ходу ловит свою ошибку: лишняя запятая в `UPDATE` → «страница не обновлена». Методический акцент: проверять результат после каждого шага.

### Видео 2 — защита админки

Задача: закрыть админку паролем, чтобы посторонний не мог набрать `/admin` и менять сайт.

Реализация в уроке:

- Готовый файл `login.php` из архива дополнений копируется в папку `admin`.
- В **начало каждого** PHP-файла админки добавляется `include "login.php";` — до любых других инструкций.
- В БД создаётся таблица `users` из трёх полей: `id` (INT, AI, PK), `user` VARCHAR(50), `pass` VARCHAR(50); вручную добавляется администратор.
- Скрипт использует HTTP Basic Auth: браузер показывает системное окно «имя пользователя / пароль», скрипт сверяет пару с таблицей и либо отдаёт страницу, либо снова показывает окно.
- Проверка: прямой заход на `edit_lesson.php` без авторизации → запрос пароля; после ввода → доступ; после перезапуска браузера → снова запрос.

### Видео 3 — финал курса

- Итоговая схема: две части сайта — публичная (только читает БД) и административная (читает и пишет), плюс БД из четырёх таблиц (`settings`, `lessons`, `articles`, `users`).
- Перенос на хостинг: экспорт четырёх таблиц из локального phpMyAdmin (файл или SQL-дамп) → создание БД и пользователя на хостинге → импорт → правка реквизитов подключения в `bd.php` в корне и в `admin/blocks/bd.php`.
- Дополнительно: место под Google AdSense, замена идентификаторов формы подписки SmartResponder, анонс следующего курса.

### Что это значит для FixPoint

Требование задания 9 — «редактирование текстов страниц» и «закрытие доступа к админке». В нашем проекте:

- доступ закрыт **сильнее**, чем в уроке: сессии + `password_hash` + CSRF + RBAC (в уроке — Basic Auth с паролем в открытом виде в БД);
- редактирование текстов реализовано **частично**: `AdminContentController` умеет править блок «О нас» (`site_content`), но не четыре страницы с мета-тегами;
- `meta description` в `app/Views/layouts/header.php` задан статически, а не из БД.

Это не P0 к защите, но честный разрыв с курсом — зафиксирован в разделе 4.

## 4. Что можно закрыть без риска для дедлайна

1. **`meta description` из БД** — добавить колонку в `site_content` и выводить в лейауте; 1 миграция + 1 шаблон + 2 теста.
2. **Редактирование текста контактов** — расширить `AdminContentController` вторым блоком по образцу «О нас».
3. **Редактирование всех четырёх страниц** — самый близкий к уроку вариант, но требует отдельной таблицы страниц и решения, какие тексты действительно живут в БД, а какие остаются в шаблонах.

Ни один из пунктов не входит в обязательный минимум P0 и не должен ломать текущий HEAD перед защитой.

## 5. Как перепроверить

```powershell
# индекс и объём
Get-ChildItem assignment/subtitles -Filter *.ru.txt | Measure-Object

# один транскрипт
Get-Content -LiteralPath "assignment/subtitles/task09-video-2 [iFwuu74H9lU].ru.txt" -Encoding UTF8

# все транскрипты одним файлом
Get-Content assignment/subtitles/full-transcript.md -Encoding UTF8 -TotalCount 40
```

Скачивание воспроизводится портативным `yt-dlp`:

```powershell
yt-dlp --skip-download --write-subs --write-auto-subs `
       --sub-langs "ru" --sub-format vtt `
       -o "<папка>/%(title)s [%(id)s].%(ext)s" "https://youtu.be/<id>"
```
