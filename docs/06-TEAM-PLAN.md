# План команды

## Backend agent
Отвечает за PHP core, router/bootstrap, controllers/services/repositories, auth/RBAC, MySQL migrations/seeds, request lifecycle, security, Docker, CI и backend tests. Не изменяет Views/assets/prototype.

## ChatGPT
Отвечает за архитектуру, integration contract, UI/UX, PHP views, CSS/JS/assets, страницы публичной части и трёх кабинетов, документацию UI и независимый QA. Не изменяет SQL, backend сервисы и контроллеры.

## Владелец проекта
Проверяет демонстрацию, решения по scope, финальную сдачу и принимает PR. Разрешает конфликт требований и приоритетов.

## Правила координации
1. Общий контракт обязателен.
2. Один исполнитель — один набор файлов.
3. Любой новый route/field/status сначала фиксируется в контракте.
4. PR маленькие, атомарные, с тестовыми доказательствами.
5. Нельзя начинать следующую крупную волну, если фундаментальная предыдущая не принята.

## Коммуникация
Агент в конце задачи сообщает SHA, ветку, изменённые файлы, команды запуска/тестов, фактические результаты, открытые вопросы и то, что осталось за рамками.
