### Две функции, которые стоит показать обязательно

1. **Сквозная заявка на ремонт:** клиент создаёт заявку → администратор назначает мастера → мастер проводит диагностику и формирует смету → клиент согласует/отклоняет → мастер обновляет статус → история сохраняет переходы.
2. **Ролевое разграничение и история:** клиент видит только свои заявки и публичные комментарии; мастер — назначенные заявки; администратор — управление. Сервер повторно проверяет права и CSRF.

## 3. Технологическая цепочка, которую надо уметь объяснить

Браузер → HTTP-маршрут → контроллер → сервис бизнес-логики → репозиторий → PDO/MySQL → модель данных в шаблон → HTML-ответ.

- **PHP 8.3** обрабатывает запросы и бизнес-правила.
- **MySQL 8** хранит пользователей, услуги, заявки, статусы, комментарии и контент.
- **PDO prepared statements** отделяют значения от SQL-запроса.
- **Миграции** воспроизводимо создают и изменяют схему.
- **Seed** заполняет БД тестовыми демонстрационными данными.
- **RBAC** проверяет роль на сервере; скрытия ссылки в HTML недостаточно.
- **CSRF-токен** защищает изменяющие запросы.
- **password_hash/password_verify** используются для паролей; открытый пароль не хранится.
