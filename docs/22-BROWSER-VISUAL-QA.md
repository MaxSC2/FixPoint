# FixPoint — browser visual QA

Цель: получать реальные скриншоты PHP-приложения, а не концептуальные изображения.

## Запуск

Workflow `.github/workflows/visual-review.yml` поднимает отдельную MySQL 8, выполняет миграции и seed, запускает PHP built-in server и Chromium через Playwright.

Результат сохраняется как GitHub Actions artifact `fixpoint-visual-review-*`: PNG-скриншоты, `report.json` и `report.md`.

## Покрытие

- Публичные страницы: главная, каталог, карточка услуги, о сервисе, контакты, вход и регистрация.
- Клиент: обзор, список заявок, создание заявки и две seeded-карточки.
- Мастер: очередь и назначенная заявка; второй мастер проверяется отдельно.
- Администратор: обзор, реестр, назначение, пользователи, услуги, категории и статистика.
- Основные ширины: 1440, 1024 и 390 px. Дополнительно главная и ключевые workspace-страницы проверяются на 768 и 360 px.

## Автоматические проверки

- HTTP-ответы и неожиданные редиректы.
- Горизонтальное переполнение документа.
- Ошибки JavaScript во время выполнения.
- Базовые WCAG 2.1 AA проверки через axe-core на desktop-снимках.
- Наличие доступных имён у интерактивных элементов и alt у изображений записывается в JSON-отчёт.

## Ограничения

Axe и DOM-метрики не заменяют ручную проверку клавиатуры, экранного диктора и реального содержимого. Скриншоты являются снимками приложения на seeded-данных, а не доказательством корректности всех бизнес-сценариев.

Пароль тестовых seed-аккаунтов существует только в CI environment. Он не сохраняется в репозитории и не предназначен для production.
