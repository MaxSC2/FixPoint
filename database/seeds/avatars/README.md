# Аватары демонстрационных мастеров

Здесь лежат картинки, которые сиядер кладёт в приватное хранилище аватаров
(`storage/private/avatars/<id>/<hash>.png`) и прописывает в
`technician_profiles.avatar_storage_key`.

- Формат: PNG, 256×256, круглая композиция (страница обрезает круг).
- Имена файлов: `master-<ключ мастера>.png` — ключ совпадает с ключом в
  `database/seeds/local_data.php` (раздел `avatars`).
- Файл заменяется на любой PNG/JPG/WebP с тем же именем: сиядер кладёт
  содержимое в приватное хранилище и переиспользует файл, если размер не
  изменился.

Аватары нарисованы как векторные иллюстрации (градиент, техническая сетка,
инициалы), поэтому они не содержат реальных людей и не требуют лицензий.
Если понадобятся настоящие портреты, положите их в эту папку под теми же
именами и перезапустите `php database/seed.php --force`.
