# Visual reference library

This directory is reserved for the actual image references used to guide UI implementation.

## Current state

No PNG/JPG reference images have been committed yet. The CSS/SVG artwork in the application is original interface illustration, not an external image-reference pack. Do not describe this folder as a completed visual pack until image files and their source records are present.

## Required reference set

- Landing page: page hierarchy, hero composition, service trust cues.
- Service catalogue: search/filter layout and service cards.
- Service detail: price estimate, scope, next action.
- Customer dashboard: repair tracking and activity timeline.
- Repair request form: compact but clear device/problem form.
- Technician queue: prioritization and operational density.
- Admin workspace: KPIs, filtering, tables and CRUD actions.
- Responsive views: header/nav, cards and forms at narrow widths.

## Recording a reference

For each image, record:
- filename and source URL;
- author or publisher;
- date accessed;
- license / reuse status;
- UI pattern being studied;
- what FixPoint adapts and what it deliberately does not copy.

Use third-party screenshots as private design research only unless redistribution and licensing are clearly allowed. Do not bundle copyrighted site screenshots into a public repository without checking permission.
